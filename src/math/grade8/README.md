# Grade 8 methods

Related methods are grouped into five domain modules, not individual activity files:

- `number.js`: scientific notation, roots, percentages, signed arithmetic and proportions.
- `algebra.js`: rational patterns, like terms, expressions, two-sided equations, inequalities and data-analysis code.
- `data.js`: paired data, scatter plots, associations/outliers, Venn regions, compound probability and experiments.
- `spatial.js`: tessellation, scale, four-quadrant transformations, metric prefixes, angles, composite measures and Pythagoras.
- `financial.js`: supplied exchange-rate scenarios, goals, interest, incentives and credit comparisons.
- `index.js`: registration, argument counts and domain checks.

All domains use the shared exact core and lesson contract. Input objects and curriculum links live in JSON, outside mathematical code. The Grade 5 and Grade 8 libraries share one renderer, grade selector and parent view. Do not copy core arithmetic into a new method.

An activity can return a caption, exact LaTeX, a diagram description, a bounded answer checker or a safe hands-on builder. Open-ended work remains unscored. See `../../curriculum/data/grade-8-research.md` for source mapping and coverage limits.
